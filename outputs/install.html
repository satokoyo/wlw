PC版Chromeで登録

  1. 上の「登録コードをコピー」を押します。
  2. ブックマークマネージャーで新しいブックマークを追加します。名前を「Wonder Deck」、URLをコピーしたコードにして保存します。
  3. Wonder.NETのカード編集画面にログインして開き、登録したブックマークを押します。

ドラッグで登録する場合、ブックマークバーは ⌘Shift+B（Windowsは Ctrl+Shift+B）で表示できます。

iPhone版Safariで登録

  1. 上の「登録コードをコピー」を押します。
  2. Safariでこのページをブックマークに追加し、名前を「Wonder Deck」にします。
  3. ブックマークを編集して、URLをコピーしたコード全体に置き換えます。先頭の javascript: も必要です。
  4. Wonder.NETのカード編集画面を開き、登録したブックマークを実行します。

コピーできないときは「コードを表示・手動でコピー」を開き、「コードを全選択」からコピーしてください。iPhone Safari実機での起動・保存は未確認です。

編集の流れ

枠を選択 → カードを検索 → 効果を確認 →「この枠にセット」。保存後も画面が続きます。上部のキャスト名から別キャストへ切り替えられます。

おすすめは先頭の専用欄に表示され、通常一覧にも表示されます。カテゴリ・レベル・効果などで絞り込めます。未所持・必要情報が未取得のカードは薄く表示され、選択できません。

ページを再読み込みした場合は再実行してください。カードの保存や拡張画面内でのキャスト切り替えでは継続して使えます。

更新するには

このページから最新コードをコピーし、登録済みブックマークのURLを置き換えます。実行中の拡張画面を「閉じる」で終了してから、更新したブックマークを実行してください。
