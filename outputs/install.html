カード名・効果・入れ替えを、ひとつの画面で。

Wonder Deck

PCでは左のボタンをブックマークバーへドラッグできます。

PC版Chrome

  1. 上の「Wonder Deck」をブックマークバーにドラッグします。バーは ⌘Shift+B（WindowsはCtrl+Shift+B）で表示できます。
  2. Wonder.NETのカード編集画面にログインして開きます。
  3. 登録したブックマークを押して起動します。

iPhone版Safari

  1. 「登録コードをコピー」を押します。コピーできない場合は下の欄を長押しして全文をコピーします。
  2. Safariで任意のページをブックマークし、名前を「Wonder Deck」にします。
  3. ブックマークを編集し、URLをコピーしたコード全体に置き換えます。先頭が javascript: であることを確認してください。
  4. Wonder.NETのカード編集画面を開き、登録したブックマークを実行します。

編集の流れ

枠を選択 → カードを検索 → 効果を確認 →「この枠にセット」。保存後も画面が続きます。上部のキャスト名から別キャストへ切り替えられます。

スキル・ソウルslot=7・マスタースキルslot=8を区別し、アシストslot=9は使用可能レベル6以上に限定します。リザーブは独立した枠として扱います。

ブラウザで再読み込みした場合は再実行してください。通信結果が未確定の場合は「保存結果を再照合」で確認します。
