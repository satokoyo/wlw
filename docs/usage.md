# WonderLandDeck 1.1.2

Wonder.NETのカード編集を1画面で行う、ブックマークレットです。

## 導入

[導入ページ](https://satokoyo.github.io/wlw/)をChromeまたはSafariで開き、「登録コードをコピー」を押してください（GitHub Pages公開後に利用可能）。クローンは不要です。公開前はGitHubの [登録用コード](../dist/wonder-deck.bookmarklet.txt) の「Copy raw file」、またはダウンロードした同じフォルダの `dist/index.html` を利用できます。PCでは「WonderLandDeck」のリンクをブックマークバーへドラッグします。iPhoneでは登録コードをコピーし、Safariのブックマーク編集画面でURLに貼り付けます。先頭の `javascript:` を含めて全文を登録してください。

登録用コードは `wonder-deck.bookmarklet.txt` にも保存しています。更新時はブックマークのURLを最新コードで置き換えて実行してください。版が違う場合、保存中でなければ表示中のキャスト・枠を引き継いで新しい画面へ切り替えます。同じ版の再実行は既存画面の再表示です。

Wonder.NETへログインし、次のいずれかの画面で登録したブックマークを実行します。

- `/deck/index.html?cast=キャストID`
- `/deck/deckchange.html?slot=枠番号&cast=キャストID&type=種別`

ページの再読み込み・別ページへの移動では終了します。その後は再実行してください。カード変更や拡張画面内のキャスト切り替えでは終了しません。

## 表示の更新（1.1.2）

カード一覧は上部にカード画像の75%、下部に94px固定の説明欄を表示します。名前・カテゴリ・レベル等・装備状態の位置を揃え、装備状態の行が空でも同じ高さを保ちます。キャスト画像は公式の2段スプライトの上段だけを表示します。

所持カードの名前一覧にレアリティが含まれず、編集中の枠の候補にも含まれない装備中カードが「情報未取得」になる問題を修正しました。公式の各種別の枠詳細から不足情報を補完します。初回など情報が足りない場合だけ、1回のキャスト読込につき各種別1回・最大4回の追加取得を順次行い、起動中はカードIDで情報を再利用します。未所持カードを所持扱いにはしません。補完できなかった場合は「再読込」で再試行できます。

## 左カラムの装備条件表示

そのカード自身の効果に装備条件がある場合だけ、左カラムのアシスト・ソウルの名前の先頭に、効果文の順で★（構成条件を満たす）、☆（不足）、？（未対応の条件・情報不足）を表示します。条件がないカードには何も付けません。リザーブ・おすすめ欄・通常一覧にも付けません。

対応するのは「このカード以外に」「レアリティがSR/WR/R/N」「カテゴリが武器/防具/装飾/道具/ソウル、またはソウルではない」「アシストカードがN枚以上発動している場合」を組み合わせた枚数条件です。同一カードの除外、ソウルの除外指定、複数条件（例：★☆、★★）を扱います。判定対象は通常デッキのアシスト4枠とソウル1枠で、リザーブは数えません。

**各カードが使用可能レベルに到達した時の装備構成の判定です。** 現在の試合レベル、HP、撃破数、時間、その他の戦闘中の発動状態は判定しません。対応しない文型を勝手に成立扱いせず、検出した装備枚数条件は「？」にします。全ての条件文を認識する機能ではありません。各カードにマウスを重ねると判定理由を確認できます。

## 操作

1. 左のデッキから編集する枠を選択します。スマホでは「デッキ」タブを使います。
2. カードをクリック・タップして効果を確認します。この段階では保存されません。
3. 「この枠にセット」を押すとWonder.NETに反映します。保存後も続けて編集できます。
4. 上部のキャスト名から別キャストに切り替えます。各キャストの設定は独立しています。

左のデッキはスキル・マスター、アシスト・ソウル、リザーブを小さなタイルで表示します。固定のワンダースキル、各枠の繰り返しラベル、強化値は省略し、カード名と画像を表示します。枠の名前はマウスを重ねたときや読み上げで確認できます。slot=9には「6+」を表示します。

カテゴリは検索欄の下にあるタブで切り替えます。通常スキルは細分類をまとめた「スキル」タブで扱います。初期値は「すべて」。枠・キャストを切り替えたときも「すべて」に戻ります。

おすすめは先頭の独立した欄に、公式のおすすめ順で表示します。この欄にはレベルの見出しを入れず、通常一覧のソートの影響を受けません。同じカードを下の通常一覧にも表示します。件数は重複を含まないカード数です。通常枠では種別・レベル条件に合うおすすめだけを表示し、リザーブでは複数種別を扱います。検索・カテゴリ・詳細フィルタは両方の一覧に適用します。

通常一覧は、通常スキル、レベル別のアシスト／ソウル、最後にマスタースキルの順です。通常スキルはアシストのレベル区分と混ぜず、独立した区画でレベル昇順・レアリティ降順に並べます。アシスト／ソウルも使用可能レベル昇順・レアリティ降順で表示します。マスタースキルは使用レベルなしとして最後にまとめ、レアリティ降順に並べます。同条件では公式候補の順序を保ちます。

カード名・カテゴリ・レベルなどは、画像の下部に続く高さ固定の説明欄に表示します。アシストのカテゴリ表示には「武器」「防具」「装飾」「道具」を使います。右の詳細欄は32×45pxのサムネイルと説明を表示し、操作ボタンが文章に重ならない配置です。長い文章は説明部分だけをスクロールできます。

未所持カードは薄く表示し、選択できません。おすすめに限らず、カード名・種別・使用レベル・レアリティ・カテゴリ・効果など必要な情報が取得できないカードも同様です。「未所持」と「情報未取得」は区別して表示します。もともと使用レベルのないマスタースキルは、レベルがないことだけを理由に無効化しません。情報が足りないカードのレベルやレアリティを推測することはありません。

検索は名前と効果文が対象です。全角・半角を正規化し、空白区切りは全単語一致。同一フィルタ項目内はOR、項目間はANDです。上昇能力は「すべて／いずれか」を選択できます。「全解除」で検索とフィルタを解除し、カテゴリを「すべて」に戻します。

## 枠制限と交換

| 枠 | カード |
|---|---|
| 通常スキル1〜3 | 対象キャストの通常スキル |
| ワンダースキル0 | 固定・左欄では非表示 |
| アシスト4〜6 | アシスト |
| アシスト9 | 使用可能レベル6以上のアシスト |
| ソウル7 | ソウルのみ |
| マスタースキル8 | マスタースキルのみ |
| リザーブ | その枠の公式候補に含まれるカード |

リザーブは通常デッキと別の枠体系です。同じ番号でも混同しません。使用可能レベルと強化値（+値・MAX）も別に扱います。

装備済みのカードを選ぶと、公式の処理で元の枠と交換します。交換元に戻るカードの種別・レベルも確認します。保存後は両方の枠と重複の有無を照合します。

保存直前にデッキ全体を取得します。別の画面で配置が変わっていた場合は保存せず、最新の配置を表示します。内容を確認して再度カードを選んでください。最後の取得後に別画面が同時更新する競合を、クライアントだけで完全に排除することはできません。保存後の照合で不一致を検出した場合は最新の構成を表示します。

## 通信と負荷

- カード編集はWonder.NETの同一オリジンに通信します。本体JSと参考値JSONはGitHub Pagesから取得します。参考値の取得には認証情報を送信しません。解析サービス・OCRは使用しません。
- 起動時に名前・効果の索引を3種取得し、起動中のメモリで再利用します。全キャストの候補を一括取得しません。
- キャスト切り替えはデッキと選択枠の候補、枠切り替えはその枠の候補だけを取得します。
- 通常の保存は、最新デッキ、変更キー、最新候補、変更処理、結果のデッキ、更新後の候補の6リクエストを順次実行します。公式画面より照合分の通信が増えますが、二重送信・古い配置での交換を防ぐためのものです。
- 検索・カテゴリ・フィルタ・追加表示は取得済みデータで処理し、API通信を発生させません。画像は表示に応じて読み込みます。
- 通常一覧は48枚ずつ追加描画し、おすすめ欄は別に表示します。既存のカード要素を再作成しません。検索入力は150msまとめて処理します。保存状況の表示変更だけでは一覧を再作成しません。
- 定期ポーリング、バックグラウンドの全カード巡回、重い画像加工はありません。閉じると通信を中断し、監視・タイマー・背景の操作抑止を解除します。

## エラー時

通信がタイムアウトして保存結果が不明なときは、次の保存を停止します。「保存結果を再照合」を使ってください。変更リクエストの自動再送は行いません。ログイン切れの場合は再ログインし、公式画面で現在の構成を確認してから起動し直してください。

## 参考ステータス（v1.2.0）

左カラムにSS・DS・スキルの掲載値小計、一覧と詳細に各カードの参考値を表示します。「計算条件・注意」で想定Lv（初期値8）と特殊効果を仮定するかを選択できます。現在の+値からの補正はありません。未収録は?または不明枚数として表示し、0としません。条件成立を自動判定した合計ではありません。

本体JSはバージョン固定URL・SRI検証付きです。更新時は導入ページからコードを再登録してください。単体版は外部JSを読み込まず起動できますが、参考JSONは外部から取得します。参考値の通信失敗はカード編集を止めません。

## v1.3.0

中央のおすすめ限定・並び順・全解除を絞り込み内へ移動し、選択条件を件数の横へまとめました。参考データは318カード・363項目に拡充。低下値、対応する装備条件と想定Lv、明記された一部の強化値を反映し、概算は≈で表示します。未収録・未補正は残るため実ダメージではありません。新しい起動コードを導入ページから再登録してください。

特殊効果の最大成長・条件達成を仮定する設定を初期ONにしました。低下効果も反映します。公式形式の効果文が取得でき、その能力への影響がないと保守的に判定できる場合は0と表示します。汎用の攻撃力強化・未知の略号・文面不足は不明のままです。特殊分だけの掲載値は、基本効果にその能力の上昇がないと公式文から確認できる場合のみ合計へ反映します。

大河創りのお札の旧HP条件SS強化は、[アシスト性能評価](https://w.atwiki.jp/wlws/pages/769.html)の現行説明と照合し除外しました。掲載値一覧間で食い違う場合があるため、全カードの実測精度を保証するものではありません。

## ビルドの共有（v1.5.0）

メニューの「エクスポート」で表示中キャストの最新配置から共有コードを作成し、コピーできます。「Xで投稿」ではキャスト名・コード・ハッシュタグ・導入URLを入力した投稿画面を開きます。投稿の確定はX上で行ってください。最大17枠で43文字。固定ワンダースキル・未解放枠・強化値・アカウント情報は含みません。未収録カードがある場合は誤ったコードを出さず停止します。

「インポート」にコードを貼り、「構成を確認」でキャスト名とカードを確認後、「この構成を反映」を押します。未所持は空欄、存在しない／未解放枠はスキップ。コードにない枠は維持しますが、移動対象カードがその枠にある場合は空欄になることを確認画面に表示します。

保存は並列にせず、結果照合後に1秒待って続けます。原則は直接セットし、交換で目的の配置になった枠は省略します。取り外しは空欄指定・未所持・直接交換できない制限がある場合だけです。進捗モーダル表示中は操作せず、ページを開いたまま待ってください。通信失敗・他画面での変更・結果未確定時は停止し、自動再送しません。途中まで完了した変更は残ります。自動ロールバックは行いません。

## v1.5.1

W2形式では最大6文字のビルド名を含められます（半角も1文字）。最大17枠で名前なし49文字・6文字名付き55文字。コードと名前全体に破損検出を含みます。旧W1形式も読込可能です。名前・コードの編集後は再コピーしてください。

確認画面は共有辞書だけで構成を復元し、公式サーバーには問い合わせません。実行の承認後に所持・解放枠を順次確認します。共有辞書は初回のみGitHub Pagesから取得。カードの一覧表示は所持確認済みを意味しません。メニューは右からスライドし、保存結果を照合した枠だけ0.5秒の発光を表示します（動きを減らす設定では無効）。

## v1.5.2

W3ではビルド名をUTF-8＋Base64urlで符号化し、共有コード全体をASCII文字だけに統一します。一般的な日本語6文字・17枠で73文字、絵文字などを含む場合は最大81文字。名前は確認画面で元の表記に戻します。チェックサムに加えてUTF-8と符号化の正当性も検証し、不正なコードは反映しません。旧W1/W2も読み込めます。


## v1.5.4 一覧・参考値

一覧は初期状態でNカードを非表示。絞り込みのレアリティでNを選ぶか全解除で表示できます。レアリティ未取得のカードは初期状態では残します。未所持・情報未取得のカードもクリックで詳細を閲覧可能ですが、セットは公式候補・所持条件に従い無効になります。効果が欠けるときだけ公開カード一覧を取得し、同じ起動中はキャッシュします。

攻撃補正への言及がない完全な効果文は0として扱います。現行値未判明は最後のWiki掲載値を使用し、†・旧掲載値で区別。小計にも旧値を含む枚数を表示します。
