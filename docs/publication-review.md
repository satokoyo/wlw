# 公開前の確認

確認日：2026-09-22。対象は公開予定のmain履歴、追跡ファイル、配布物と画面キャプチャです。リポジトリの公開範囲はこの作業では変更しません。

## 確認と修正

- mainの全履歴に含まれるテキストを、一般的なアクセストークン・秘密鍵・個人メール・ローカル絶対パスのパターンで検査。該当する秘密情報は検出しませんでした。
- コミットの作者に個人用メールアドレスを発見し、noreply表記に修正しました。今後のローカルコミットもリポジトリ単位でnoreplyを使用します。
- ソース・テスト・ビルド・サイト素材・配布物・説明を専用フォルダへ分離しました。
- .env、秘密鍵ファイル、Gitバックアップ、作業フォルダ、依存環境をGitの除外対象に追加しました。
- APIキー・パスワード・セッションCookie・公式変更キーを固定値として保存する実装はありません。テストの変更キーは架空の文字列です。
- 画面キャプチャにはゲーム内カード配置と強化値が含まれます。ブラウザのタブ・ブックマーク・アドレスバー、アカウント名、メールアドレスは含みません。画像のEXIF等の個人メタデータも含みません。
- 架空のテストデータと検証手順は保持し、公式APIの生レスポンスや個人の元デッキ記録はリポジトリへ追加していません。
- Pagesの配信対象をdistだけに限定しています。ローカルの作業フォルダや履歴バックアップは配信しません。

## 確認の限界

パターン検査はあらゆる秘密情報の不存在を証明するものではありません。画像内のカード情報などは説明のため意図して掲載しています。

作者情報の修正はmainの到達可能な履歴に対するものです。GitHubに既に送信した旧コミットは、既知のSHA・キャッシュ・既存クローン等から直ちに消えるとは限りません。履歴変更を完全消去と扱わないでください。GitHub上の旧履歴の消去が必要な場合は別途対応が必要です。

第三者の画像・商標・ゲームデータの掲載許諾を法的に確認したものではありません。著作権表記だけで許諾が得られるわけではなく、本リポジトリで作成したコード・説明文にはMITライセンスを設定済みです。第三者のゲーム素材は対象外です。

iPhone Safari実機の起動・保存、全キャスト・全カードの挙動保証は対象外です。機能の検証範囲は[検証結果](verification.md)を参照してください。
